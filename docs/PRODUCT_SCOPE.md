# PRODUCT SCOPE

Objetivo: construir uma plataforma operacional digital para corretor de imóveis, partindo de uma aplicação imobiliária open source funcional e evoluindo-a progressivamente.

Princípios:
- Não reconstruir o produto do zero.
- Alterar e ampliar uma base funcional sempre que tecnicamente viável.
- O código existente é a fonte de verdade.
- Não inventar APIs, tabelas, rotas, credenciais ou dependências.

Escopo inicial:
- Imóveis residenciais, comerciais, terrenos e rurais.
- Venda, compra, locação e captação.
- Proprietários, compradores, locatários e leads.
- CRM, WhatsApp, visitas, propostas, negócios, documentos, matching, prospecção, automações, analytics e futura camada de IA.
