# Security Policy

## Supported Versions

Currently, this repository is in its initial documentation and architectural
planning phase. All active development branches are supported.

## Reporting a Vulnerability

We take the security of our project seriously. If you discover a security
vulnerability, we kindly ask you to report it to us privately to allow us time
to investigate and fix the issue before public disclosure.

Please report any security vulnerabilities directly to the project author and
primary contact:

**Email:** <igorbrito.n1@hotmail.com>

### What to include in your report

* A description of the vulnerability.
* Steps to reproduce the vulnerability (if applicable).
* Any potential impact or risk associated with the vulnerability.

We will endeavor to respond to your report as quickly as possible, usually
within 48 hours, and will keep you informed of our progress towards a
resolution.

Please **do not** report security vulnerabilities via public GitHub issues.
