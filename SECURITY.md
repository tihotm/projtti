# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of this project very seriously. If you discover a security vulnerability in this project, please report it privately.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please send an email to the project maintainer:
**igorbrito.n1@hotmail.com**

Please include the following information in your report:
- Type of vulnerability (e.g., XSS, SQLi, RCE)
- Description of the vulnerability and its potential impact
- Steps to reproduce the vulnerability
- Any relevant logs, screenshots, or proof-of-concept code

We will acknowledge your report as soon as possible and work to resolve the issue promptly. We will keep you informed of our progress.
