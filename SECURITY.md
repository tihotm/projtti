# Security Policy

## Supported Versions

Currently, this repository is documentation-focused and setting up the base architecture.

## Reporting a Vulnerability

We take the security of this project very seriously.

If you discover a security vulnerability, please report it immediately by sending an email to the project author and primary contact: **igorbrito.n1@hotmail.com**.

Please **DO NOT** create a public issue or pull request with details of the vulnerability, to avoid exposing it before a fix can be implemented.

We will review your report and respond as quickly as possible.
