# Security Policy

## Supported Versions

Currently, this repository is documentation-focused and contains architectural decisions. Security updates will be applied to the main branch as needed.

## Reporting a Vulnerability

We take the security of our project seriously. If you discover a security vulnerability, please report it privately.

**Do not report security vulnerabilities through public GitHub issues.**

Instead, please send an email to the primary contact for security vulnerability reports:
**igorbrito.n1@hotmail.com**

Please include the following details in your report:
- Description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact.

We will acknowledge receipt of your vulnerability report and strive to address the issue promptly.
