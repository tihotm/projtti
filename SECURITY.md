# Security Policy

## Supported Versions

Currently, this repository contains only documentation and architectural decisions for the base project. Once the application is built, supported versions will be listed here.

## Reporting a Vulnerability

We take the security of our systems seriously. If you discover a security vulnerability in this project, please report it privately.

**Do not publicly disclose the vulnerability until it has been addressed.**

### Primary Contact

Please report all security vulnerabilities to the project author and primary contact:
**Email:** [igorbrito.n1@hotmail.com](mailto:igorbrito.n1@hotmail.com)

### What to include in your report

- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue.
- Any relevant code snippets, logs, or screenshots.

We will acknowledge receipt of your vulnerability report and strive to provide a resolution or an update as quickly as possible.
