# Security Policy

## Supported Versions

Currently, this repository consists of documentation and architectural plans.

## Reporting a Vulnerability

We take the security of this project seriously. If you discover a security vulnerability, please report it to us privately so we can investigate and address it before public disclosure.

Please report any security vulnerabilities to the project author at: **igorbrito.n1@hotmail.com**

We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress. Please do not open public issues for security vulnerabilities.
