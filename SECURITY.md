# Security Policy

## Supported Versions

Currently, the master branch is the only supported version for security updates.

| Version | Supported          |
| ------- | ------------------ |
| master  | :white_check_mark: |

## Reporting a Vulnerability

Please do not open a public issue if you find a security vulnerability.

Instead, report it privately to the project author and primary contact via email: `igorbrito.n1@hotmail.com`.

We take security issues seriously and will respond to your report as quickly as possible.
