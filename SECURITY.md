## Reporting a Vulnerability

We take the security of our project seriously. If you discover a security vulnerability, please **do not report it publicly in an issue or on social media**.

Instead, please report it directly to the project author via email:
**igorbrito.n1@hotmail.com**

Please include the following information in your report:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Any potential impact you foresee.

We will review the report and work with you to resolve the issue as quickly as possible.
