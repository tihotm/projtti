# Security Policy

## Supported Versions

Currently, this repository consists entirely of documentation, audits, and architectural decisions. There are no supported versions of application or frontend UI code at this time.

## Reporting a Vulnerability

Security is a priority. If you discover any security vulnerabilities in the documentation, architectural decisions, or future application code, please report them directly via email.

**Primary Contact:** igorbrito.n1@hotmail.com

Please provide a detailed description of the issue, including steps to reproduce the vulnerability (if applicable). We will endeavor to respond to your report as quickly as possible. Please do not disclose the vulnerability publicly until it has been resolved.
