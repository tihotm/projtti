# Security Policy

## Supported Versions

Please check the project roadmap and current active branches to see which versions are currently supported with security updates.

## Reporting a Vulnerability

We take the security of our project seriously. If you discover a security vulnerability, please do NOT report it by creating a public GitHub issue.

Instead, please send an email to igorbrito.n1@hotmail.com detailing the vulnerability. We will endeavor to respond within 48 hours and provide a timeline for a fix.

Please provide the following details in your report:
- A description of the vulnerability and its impact.
- Steps to reproduce the issue.
- Any potential mitigation or workarounds.

Thank you for helping keep this project secure!
