# Security Policy

## Supported Versions

Currently, this repository is documentation-focused and acts as a base project. Only the latest main branch is supported.

## Reporting a Vulnerability

Security is a high priority for this project. If you discover a security vulnerability, please do not disclose it publicly or submit a public pull request.

Instead, please report it immediately by sending an email to the primary contact:

**Email:** [igorbrito.n1@hotmail.com](mailto:igorbrito.n1@hotmail.com)

Please include the following details in your report:
- A description of the vulnerability and its potential impact.
- Detailed steps to reproduce the issue.
- Any suggestions you may have for a fix.

We will review the submission and respond as quickly as possible. We ask that you maintain confidentiality until we have had an opportunity to address the issue.
