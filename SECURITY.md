# Security Policy

## Supported Versions

The following versions of the project are currently being supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

If you believe you have found a security vulnerability, please report it to the primary contact for security vulnerability reports: **igorbrito.n1@hotmail.com**.

Please include the following information in your report:
- The type of vulnerability
- The steps to reproduce the vulnerability
- Any relevant logs or screenshots

We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress. If you have not received a reply to your email within 48 hours, please follow up to ensure we received your message.
