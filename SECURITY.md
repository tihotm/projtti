# Security Policy

## Supported Versions

Currently, this repository contains primarily documentation and architectural decisions. All versions are currently supported for security updates.

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please report it immediately.

The project author and primary contact for security vulnerability reports is **igorbrito.n1@hotmail.com**.

Please allow a reasonable amount of time for a response before making any information public. We take all security reports seriously and will work to address any verified issues.
