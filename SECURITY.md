# Security Policy

## Supported Versions

Currently, this repository is focused on documentation, audits, and architectural decisions, and does not contain application code. Thus, versioning for support is not applicable in the traditional sense.

## Reporting a Vulnerability

We take the security of this project seriously. If you believe you have found a security vulnerability in any related systems or documentation, please report it to us privately.

**Do not report security vulnerabilities through public GitHub issues.**

Instead, please send an email to the project author and primary contact: **igorbrito.n1@hotmail.com**

Please include the following details in your report:
- A description of the vulnerability and its potential impact.
- Detailed steps to reproduce the issue.
- Any relevant context or background information.

We will acknowledge receipt of your vulnerability report and strive to address it promptly.
