# Security Policy

## Supported Versions

This repository currently only contains documentation. As such, there are no specific application versions to support for security updates at this stage.

## Reporting a Vulnerability

We take the security of this project very seriously. If you discover a security vulnerability within this project, please send an e-mail to **igorbrito.n1@hotmail.com**.

All security vulnerabilities will be promptly addressed. Please do not disclose the issue publicly until a fix has been released.

Please include the following information in your report:
* A description of the vulnerability.
* Steps to reproduce the issue.
* Any possible mitigation steps.
