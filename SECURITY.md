## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, please send an email to the primary contact for security vulnerability reports: **igorbrito.n1@hotmail.com**.

We take all security vulnerabilities seriously and will try to respond to you within 48 hours.
