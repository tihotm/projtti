# Security Policy

## Supported Versions

Since this repository currently contains documentation and architectural decisions, all versions are essentially supported for reporting structural or architectural security concerns.

## Reporting a Vulnerability

We take the security of this project seriously.

If you discover a security vulnerability within this project, please send an e-mail to **Igor Brito** via [igorbrito.n1@hotmail.com](mailto:igorbrito.n1@hotmail.com).

Please do not report security vulnerabilities through public GitHub issues.

All security vulnerabilities will be promptly addressed.
