# Security Policy

## Supported Versions
Currently, all active development is supported for security updates.

## Reporting a Vulnerability

We take the security of this project seriously.
If you believe you have found a security vulnerability, please report it to us as described below.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them privately by emailing the project author and primary contact for security vulnerability reports at **igorbrito.n1@hotmail.com**.

You should receive a response within 48 hours. If for some reason you do not, please follow up via email to ensure we received your original message.

We appreciate your effort in making this project safer!
