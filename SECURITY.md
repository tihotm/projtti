# Security Policy

## Supported Versions

Currently, this repository is focused on documentation, audits, and architectural decisions. There are no running application versions to support at this time.

## Reporting a Vulnerability

We take the security of our platform seriously. If you discover a security vulnerability in this project, please report it privately. **Do not create a public issue.**

Please report any security vulnerabilities directly to the primary contact at: **igorbrito.n1@hotmail.com**

When reporting, please include:
- A description of the vulnerability and its impact.
- Steps to reproduce the issue (if applicable).
- Any potential mitigation or solutions you suggest.

You should receive a response acknowledging receipt of your report within 48 hours. We will keep you updated on the progress of addressing the vulnerability.
