# Security Policy

## Supported Versions

Currently, this repository is focused on documentation, audits, and architectural decisions, and does not contain application or frontend UI code.

## Reporting a Vulnerability

Security is a priority. If you discover a security vulnerability within this project, please report it immediately.

**Primary Contact for Security Vulnerability Reports:**
igorbrito.n1@hotmail.com

Please include the following details in your report:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Any potential impact.

We will review the issue and respond as quickly as possible. Please avoid disclosing the vulnerability publicly until it has been addressed.
