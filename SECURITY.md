# Security Policy

## Supported Versions

This repository currently consists entirely of documentation, audits, and architectural decisions. As it does not contain executable code for the application, standard software versioning for security updates does not strictly apply. However, all documented security principles are actively maintained.

## Reporting a Vulnerability

We take the security of this project seriously. If you discover a security vulnerability or have a security concern related to the architectural decisions, documentation, or related audits, please report it to us.

**Do not report security vulnerabilities through public GitHub issues.**

Please report any security vulnerabilities directly to the project author at:
**igorbrito.n1@hotmail.com**

When reporting, please include:
*   A description of the vulnerability or security concern.
*   The potential impact of the vulnerability.
*   Steps to reproduce or understand the issue.

We will endeavor to respond to your report promptly and address the issue responsibly.
