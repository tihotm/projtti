# Security Policy

## Supported Versions

Since this repository primarily consists of documentation and architectural decisions, all content on the main branch is considered current and supported.

## Reporting a Vulnerability

We take the security of our platform and its architecture seriously. If you discover a security vulnerability or have a security-related concern regarding the architectural design, please report it to the project author.

**Primary Contact:**
igorbrito.n1@hotmail.com

Please include the following details in your report:
* A description of the vulnerability or security concern.
* The specific area of the documentation or architecture affected.
* Any potential impact or exploitation scenario.
* Suggested mitigation or fix (if known).

We aim to acknowledge all reports within 48 hours and provide an estimated timeline for resolution.
