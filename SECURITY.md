# Security Policy

## Supported Versions

Since this project consists of architectural decisions, audits, and documentation, the most recent version on the main branch is considered currently supported.

| Version | Supported          |
| ------- | ------------------ |
| Main    | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

We take the security of our platform and its architecture very seriously.

If you discover a security vulnerability within this repository, its architecture, or potential risks in the documented decisions, please **do not** create a public issue.

Instead, please send an e-mail to the project author and primary contact for security vulnerability reports at **igorbrito.n1@hotmail.com**.

We will review your report and respond as quickly as possible with next steps and a timeline for remediation.
