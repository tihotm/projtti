# Security Policy

## Supported Versions

Currently, this repository consists entirely of documentation, audits, and architectural decisions. Therefore, there are no specific versions of software to support or patch. However, the architectural principles described within these documents are actively maintained.

## Reporting a Vulnerability

We take the security of our platform and its underlying architecture very seriously. If you discover a security vulnerability within this project (e.g., in our architectural designs, documentation, or associated infrastructure), please report it to us immediately.

**Do not disclose the vulnerability publicly until it has been addressed.**

Please report any security issues or vulnerabilities by emailing the primary contact:

**Email:** [igorbrito.n1@hotmail.com](mailto:igorbrito.n1@hotmail.com)

Please include the following information in your report:
* A description of the vulnerability and its potential impact.
* Detailed steps to reproduce the issue, if applicable.
* Any relevant documentation or references.

We will endeavor to respond to your report as quickly as possible, typically within 48 hours, and keep you informed of our progress towards a resolution.
