# Security Policy

## Supported Versions

Currently, this repository is documentation-focused and does not contain active application code.

## Reporting a Vulnerability

Security is a top priority. We appreciate your efforts to responsibly disclose your findings.

If you discover a security vulnerability in this project, please report it immediately by sending an email to the project author and primary contact for security vulnerability reports: **igorbrito.n1@hotmail.com**.

Please do **not** report security vulnerabilities through public GitHub issues.

We will acknowledge your email and work to resolve the issue as quickly as possible.
