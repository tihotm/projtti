## Reporting a Vulnerability

We take the security of our project seriously. If you discover a security vulnerability in this project, please report it immediately.

**Do not create a public issue.**

Instead, please email the project author and primary contact for security vulnerability reports directly at:

**igorbrito.n1@hotmail.com**

Please include the following information in your report:
*   A description of the vulnerability.
*   Steps to reproduce the issue.
*   Any potential impact or risk.

We will review the report and respond as quickly as possible.
