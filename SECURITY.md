# Security Policy

## Supported Versions

Currently, this repository is documentation-focused and does not contain active application code.

## Reporting a Vulnerability

We take the security of our project seriously.
If you believe you have found a security vulnerability, please report it to us directly.

Please contact **Igor Brito** at **igorbrito.n1@hotmail.com** to report any security vulnerabilities.

We ask that you do not disclose the vulnerability publicly until we have had a chance to address it. We will try to get back to you as soon as possible.
