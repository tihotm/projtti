# Security Policy

## Supported Versions

Currently, this repository contains documentation and audits for the new real estate platform (`plataforma-imobiliaria`).
As such, versioning is not strictly applicable to code, but security concerns related to the architectural decisions, exposed information, or future implementations are taken seriously.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

If you believe you have found a security vulnerability, please report it to the project author and primary contact for security vulnerability reports at:

**igorbrito.n1@hotmail.com**

Please include the following information in your report:
- Type of vulnerability (e.g., exposed sensitive information, architectural flaw).
- A detailed description of the issue.
- Any relevant files or documentation lines.

You should receive a response acknowledging receipt of your vulnerability report within a reasonable timeframe. We ask that you maintain confidentiality until the issue is resolved.
