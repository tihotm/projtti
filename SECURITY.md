# Security Policy

## Supported Versions

Currently, this repository is for documentation, audits, and architectural decisions, so version support does not strictly apply in terms of a software product. However, any security concerns regarding the architecture or plans described here should be reported.

## Reporting a Vulnerability

Security is a priority. If you discover a security vulnerability within this repository's contents (such as leaked credentials, unsafe architectural decisions, or other issues), please report it responsibly.

Please report any security vulnerabilities by emailing the primary contact: **igorbrito.n1@hotmail.com**.

We will endeavor to respond to your report as quickly as possible and work with you to address the issue. Please do not disclose the vulnerability publicly until it has been addressed.
