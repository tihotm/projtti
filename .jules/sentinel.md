## 2024-05-18 - Establish Responsible Disclosure Policy
**Vulnerability:** Missing security policy for reporting vulnerabilities safely.
**Learning:** Even for a documentation and architecture-focused repository without functional code yet, establishing a responsible disclosure policy early is crucial to ensure that any architectural security gaps or future implementation vulnerabilities are reported privately rather than publicly.
**Prevention:** Always ensure a `SECURITY.md` file is present in the repository root with a clear, private contact method (e.g., email) before significant application code is written.
