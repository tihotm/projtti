## 2023-10-27 - Security Policy Addition
**Vulnerability:** Missing standard security disclosure policy.
**Learning:** The project is entirely documentation-based at this early stage. No code vulnerabilities were present to fix. A `SECURITY.md` file was added to establish a secure reporting process for the project author.
**Prevention:** Always maintain a `SECURITY.md` file from the start of a project to ensure security researchers have a clear path to report issues securely.
