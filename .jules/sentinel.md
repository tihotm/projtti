## 2025-02-23 - [Security Enhancement] Add Responsible Disclosure Policy
**Vulnerability:** Missing `SECURITY.md` file detailing a responsible disclosure policy.
**Learning:** Even documentation-focused base repositories need a clear way for users and researchers to report potential security issues found in architecture decisions, or subsequent code additions, before they are made public.
**Prevention:** Always include a `SECURITY.md` policy from the inception of a repository, directing security reports to a designated contact (e.g., `igorbrito.n1@hotmail.com`).
